# Architecture Diagrams

Reference figures for the Trend Trawler pipeline. Generated with the PaperBanana
MCP figure pipeline. Kept here for easy viewing — only the accurate ones are
embedded in the top-level `README.md`. Superseded versions live in [`archive/`](archive/).

| `system-architecture.png` | ✅ Accurate — embedded in `README.md` + `deployment/README.md` | End-to-end system (**regenerated 2026-10-14**). Four bands. Users and Cloud Run services: team users → IAP (domain-restricted) → `trend-trawler-web` (Next.js, `/api/adk` proxy) → ID token + `X-TT-User` → the private `trend-trawler-api` (`async_app`: `/runs`, `/ratings`, `/shares`, `/person-refs`, `/variants`, `/experiments`); anyone with a link → the public `trend-trawler-share` (`/s/<token>` only). Agents and models (Vertex AI): Agent Engine `trend_scout`, `creative_agent`, `interactive_creative`, the `trend-trawler-sessions` Agent Engine (the api's sessions; it runs the agents in-process), the Gemini models (`gemini-3.8-flash`, `gemini-3.1-pro-preview` judge, `gemini-3.5-flash`, `gemini-nano-banana-2.1`, Google Search grounding) and the bandit endpoint (LinTS) + synthetic traffic job. Data: BigQuery `trend_digest`, `target_trends_crf`, `trend_creatives`, `creative_evals`, `creative_ratings`, `creative_shares`, `person_references`, the bandit tables, and Cloud Storage (reports, images, `shares/`, `person-refs/`). Batch and CI: Pub/Sub `creative-eventarc-topic` → Eventarc → orchestrator `creative-trawler-crf` → Cloud Tasks `creative-worker-queue` → worker `creative-worker-crf` (runs the `creative_agent` engine, writes row state); the nightly eval CI (GitHub Actions, WIF) → `adk eval` → `trend_trawler_eval` dataset. Previous (2026-10-12) version: [archive/system-architecture_2026-10-12.png](archive/system-architecture_2026-10-12.png) (no `trend_digest`, worker reached by Pub/Sub + Eventarc, no eval CI); 2026-09-29: [archive/system-architecture_2026-09-29.png](archive/system-architecture_2026-09-29.png) (no share service, ratings/shares/person tables or bandit; image model shown as `gemini-3.1-flash-image`). |
